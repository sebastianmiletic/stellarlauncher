# Archive identity

Original Archive Launcher artwork, created as editable SVG for this project. Licensed under CC BY-SA 4.0, matching the upstream artwork license. Existing Prism artwork and notices remain attributed to their original authors.

- `archive-mark.svg`: editable square master.
- `archive-logo.png`: 1024px export with transparency outside the mark.
- `archive-wordmark.svg`: horizontal dark-surface wordmark.
- `app.archivelauncher.ArchiveLauncher.svg`: embedded app mark.
- `archive-launcher.icns`, `archive-launcher.ico`, `archive.iconset/`: OS exports.

Design brief: a minimal isometric block chest, with an amber lid, copper faces, a dark seam and a gold latch. Minecraft-inspired geometric identity, without using Minecraft's logo or textures. Created directly in SVG; no image generation service was used.
